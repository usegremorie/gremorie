## Overview

`QrCode` turns a string into a scannable code. The matrix is built by [`uqr`](https://github.com/unjs/uqr), a zero-dependency encoder, and the dark modules are painted as a single SVG `<path>` with `currentColor`. Color comes from tokens: dark modules on a light plate (`text-gray-950` on `bg-gray-50`) in every theme, including dark mode, because many camera readers fail on an inverted code. There is no raster image and nothing to recolor by hand.

The four-module quiet zone scanners need is part of the box, so the code stays readable on any card, sheet, or page as long as the surface behind it is plain. Pick an error correction level (`ecc`) for how much damage the code should survive, a `size` from the spacing scale, and optionally place a mark in the center.

## API

### `<QrCode>`

| Prop         | Type                       | Default     | Description                                                                                       |
| ------------ | -------------------------- | ----------- | ------------------------------------------------------------------------------------------------- |
| `value`      | `string`                   | required    | Text the code encodes, usually a URL. A value too long for the largest code renders an empty box. |
| `ecc`        | `"L" \| "M" \| "Q" \| "H"` | `"M"`       | Error correction level: about 7, 15, 25, and 30 percent of the code can be lost.                  |
| `size`       | `"sm" \| "md" \| "lg"`     | `"md"`      | Square box of 128, 192, or 256 px (`size-32`, `size-48`, `size-64`).                              |
| `aria-label` | `string`                   | `"QR code"` | Accessible name of the code (`role="img"`).                                                       |
| `icon`       | `ReactNode`                | -           | Mark centered over the code. In Angular, project it as content.                                   |
| `className`  | `string`                   | -           | Extra classes merged via `cn`.                                                                    |

All other `div` props are forwarded. The `qrCodeVariants` CVA function is also exported.

## Variations

### Error correction

Higher levels add redundancy, so the code gets denser (more modules) but survives more damage or a larger center mark.

```tsx
<QrCode ecc="L" value={url} />
<QrCode ecc="H" value={url} />
```

### Center icon

```tsx
<QrCode ecc="H" icon={<SparklesIcon aria-hidden="true" />} value={url} />
```

## Accessibility

- **Name the code**: the box is a single image, so give it an `aria-label` that says what scanning does (for example "Pairing code"). The default is the generic "QR code".
- **Offer a non-scanning path**: a code is not usable by everyone. Show the link or a short code as text nearby for people who cannot scan.
- **Never inverted**: the code keeps dark modules on a light plate in dark mode too. Many scanner apps fail on light-on-dark codes.
- **Contrast**: `gray-950` on `gray-50`, the highest-contrast pair of the palette.
- **Center icon**: raise `ecc` to `Q` or `H` and test a real scan before shipping a large mark.
