Assistant: the four composer parts are now switchable.

`mentions`, `contextMeter`, `modeSelect` and `modelSelect` all default to
`true`, so the block still arrives complete and you strip what your product
does not have instead of forking the source to remove it. Turning off both
header parts drops the header rather than leaving an empty strip above the
textarea.

The React edition gained the same four props in the same commit; the block's
doc page now lists all eight props it accepts.
